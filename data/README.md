# Inventario de ejemplo

`inventario.json` es la **única fuente de datos** usada por Python y la demo JavaScript.
Los importes se expresan en **céntimos de sol (PEN)** para garantizar cálculos exactos.

- Todos los productos, unidades y precios son ficticios.
- No contiene información sensible ni contraseñas.
- El servidor expone únicamente consultas: no modifica el catálogo.
- La demo web muestra un recorrido didáctico, **no es un cliente MCP conectado**.
